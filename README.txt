قالب منصة الزاهرة للتدريب — الإصدار 4.8.4
==========================================

تحديث 4.8.4 (Catalog density + accessibility handoff):
- كتالوج المنتجات التدريبية يحافظ على ارتفاع طبيعي وبطاقة مفردة متوسطة الحجم، بينما تبقى المنتجات المتعددة ضمن شبكة الدورات.
- إزالة كل أصول الأيقونات القديمة غير المستخدمة (favicon.svg / favicon.ico / favicon-*.png / apple-touch-icon.png)؛ روابط التبويب واللمس تستخدم assets/logo-mark.png فقط.
- إصلاح تسمية الشريط الجانبي المطوي H5 يبقى ضمن Alzaherah Platform Core لأن CSS الخاص به مملوك للإضافة.
- عقد توافق مع Platform Core 3.0.8.

تحديث 4.8.3 (Training products page + checkout parity):
- قالب page-training-products.php بنفس هيكل صفحة الدورات (Hero واحد + شبكة كاملة العرض).
- نصوص صفحة التسجيل والدفع تتغير حسب نوع السلة: دورة / منتج رقمي / مختلط.
- ملخص الطلب يعرض غلاف المنتج والكمية والسعر وملاحظة تنزيل 90 يومًا بدل مقاعد الدورة.
- عقد توافق مع Platform Core 3.0.7.

تحديث 4.8.2 (Homepage training products + exact brand favicon):
- عقد توافق مع Platform Core 3.0.6.
- إضافة قسم مستقل للمنتجات التدريبية الرقمية المنشورة في الصفحة الرئيسية بنفس بطاقات السعر الأساسي وسعر العرض المعتمدة في صفحة المنتجات.
- استخدام ملف علامة الزهرة الزرقاء نفسه الظاهر في رأس الموقع كأيقونة للتبويب وApple Touch Icon، وإيقاف أولوية رسم SVG القديمة ذي الخلفية البنفسجية.
